## 一、背景与定位

为了直观呈现本地技能农场（35 个技能、12 个能力内聚族群、5 大主流 Agent 挂载拓扑）的健康状态，并为后续无缝接入全机监控中枢 `monitor-panel`（`/home/dc/projects/monitor-panel`）提供稳定底座，制定本规格。

### 核心定位原则
1. **只读观察与零配置写入口（Read-only Cockpit）**：
   - 驾驶舱仅作为当前能力资产期望态、断言态与运行态的只读投影视图；
   - 严禁在界面提供反写配置按钮，绝对维护 `agent-map.yaml` 作为全机唯一事实源的权威性，所有变更仍严格收敛至 Git 与 CLI（`skills-sync` / `family-apply`）。
2. **跨系统单向解耦（Unidirectional Decoupling）**：
   - `dc-skills` 负责以原子写入方式落盘持久化快照文件；
   - `monitor-panel` 仅作为同机只读消费者异步读取文件，两端不建立任何跨仓进程调用或网络依赖。
3. **工业级极简视觉（Linear / Vercel Dark Aesthetics）**：
   - 全面抛弃高饱和度彩色与 Emoji 符号堆叠，采用 Zinc 碳黑调色板、等宽数值字体与高内聚族群树形呈现。

## 三、状态快照数据契约（Schema v1）

快照持久化于 `~/.local/state/dc-skills/skills-snapshot.json`（遵循 Linux XDG State 规范，持久保存且不污染 Git 工作区）。

### 3.1 完整 JSON Schema 结构范例

```json
{
  "schema_version": 1,

    "offline": true
  },
  "summary": {

    "families_total": 12,

    "load_modes": {
      "auto": 12,

    {

      "deps": {
        "cli": ["git", "gh"],
        "mcp": ["codegraph"]
      }
    }
  ],
  "skills": [
    {
      "name": "proxy-ops",
      "family": null,

        "mcp": []

      "status_hint": "正常",
      "description": "当用户要排查或切换本机梯子、mihomo、Taishan 或系统代理时使用..."
    }
  ]
}
```

### 3.2 字段语义与约束
- `schema_version`：整数版本号，固定为 `1`。字段演进坚持“只增不删”原则；任何破坏性结构重构必须递增版本。
- `mounts` 状态枚举：
  - `mounted`：既符合 `agent-map.yaml` 挂载期望，且磁盘软链物理存在（正常）；
  - `missing`：符合期望但在宿主目录缺失软链（异常漂移）；
  - `extra`：未声明挂载却在宿主目录存在软链（孤儿软链）；
  - `unmounted`：正常未挂载至该 Agent。
- `status` 状态枚举：`ok`（正常）、`warn`（存在非致命基线警告）、`crit`（存在严重契约阻断）。

### 3.3 原子写入与并发安全
采用 POSIX 同目录重命名机制，杜绝消费端读到截断的脏数据：
```python
dest = Path("~/.local/state/dc-skills/skills-snapshot.json").expanduser().resolve()
dest.parent.mkdir(parents=True, exist_ok=True)
tmp = dest.with_name(f".{dest.name}.tmp.{os.getpid()}")
tmp.write_text(json.dumps(doc, ensure_ascii=False, indent=2), encoding="utf-8")
os.replace(tmp, dest)
```

## 四、离线 HTML 技能驾驶舱设计规范

生成于 `skills-output/dashboard/skills-dashboard.html`，设计完全自包含，无任何外网 CDN 脚本请求。

### 4.1 视觉系统规范（Zinc 碳黑工业级）
- **调色板**：
  - 背景：`--bg: #09090b`；卡片底板：`--card-bg: #121215`；边框：`rgba(255, 255, 255, 0.07)`；
  - 文字主色：`#f4f4f5`；次要文字：`#71717a`；消隐暗色：`#52525b`。
- **排版字体栈**：
  - 界面通用字：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`；
  - 数值、Commit、耗时、代码标识：`"JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, monospace`，启用 `tabular-nums` 等宽对齐。
- **全站符号化**：彻底剔除彩色 Emoji，采用 6px 几何圆点（`●`）、状态箭头（`▸` / `▾`）及纯文本徽章。

### 4.2 模块功能与排版布局
1. **顶栏（Header）**：
   - 标题与版本徽章（`v1.1`）单行水平对齐；
   - 右侧通过暗色胶囊展示格式化时间戳（`YYYY-MM-DD HH:MM:SS`）、Commit Hash 与毫秒耗时。
2. **KPI 状态矩阵**：
   - 主库托管技能总数、能力内聚族群数；
   - 启动清单注入状态：高亮对比 `12 Auto 入口` / `23 Manual 按需`；
   - 全资产巡检状态：以 `6px` 实心圆点展示 `0 异常`、`5 警告`（琥珀色）、`23 正常`（翠绿色）。
3. **紧凑单行工具栏（Toolbar）**：
   - 包含实时搜索框、族群/角色/加载模式/巡检状态 4 组联动下拉框；
   - 右侧暗色凹槽分段控制器切换 `族群视图` 与 `平铺表格`，配全部展开/折叠辅助操作。
4. **族群能力聚合树（Family Card View）**：
   - 以族群为独立卡片，头部汇总依赖（`CLI:git, gh` / `MCP:codegraph`）与构成徽章；
   - **族内告警透传**：若族内技能存在警告或异常，折叠头部直接显示 `● 1 警告`，折叠态一览无余；
   - **👑 入口技能网关**：3px 翠绿左饰线，显示 `entry · auto` 复合标签；
   - **↳ 族内从属技能树**：虚线分支连接从属成员，显示 `member · manual` 复合标签；
   - **异常显式透出**：存在警告的技能（如门禁超标），无需鼠标悬停，正文下方直接呈现琥珀色告警诊断说明。
5. **独立技能专区（Standalone Card）**：
   - 独立卡片展示 `proxy-ops` 等无族群归属的运维技能，标明 `standalone · manual`，体现全 Agent 可见且零上下文占用特性。
